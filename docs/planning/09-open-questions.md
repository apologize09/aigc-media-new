# 9. 已确认结论与剩余问题

2026-10-16 收到一批答复。已经写进第 1 至第 8 篇的，以那些篇章为准。本篇保留结论原文和仍然不能编造的空位。

## 9.1 已确认（2026-10-16）

| 编号 | 答复 | 写入规划后的规则 |
| --- | --- | --- |
| Q1 | 客户只收链接 | 客户无账号。审核通过后交付可撤销链接。客户批注留在第二阶段 |
| Q2 | 素材可以出域 | worker 可以把需求文本和素材二进制发给已配置的模型供应商。供应商名称这次没有给 |
| Q3 | 可以转存 | 选用网络案例后，把副本存进对象存储并保留来源。授权状态默认未知。搜索供应商和必须覆盖的站点这次没有给 |
| Q4 | 三种职责加财务开关，隔离 | 管理员、方案编辑、审核人。财务可见是开关，不是第四种角色。管理员看全部项目，其他人只看自己参与的项目。没有要求禁止自审 |
| Q5 | 暂无公式 | 不计算利润率，不预置税率、币种和费率。利润区显示未配置。金额只来自人工录入 |
| Q6 | 不做行业模板，任务以手工为主 | 不按业务类型生成模块模板或任务包。任务接口只有手工创建和确认 |
| Q7 | 单人审核 | 一名审核人通过即视为该快照通过。退回和再次通过都保留历史记录。不做会签 |
| Q8 | 可撤销；旧链接指向旧快照 | 撤销使该链接失效。新版本不改旧链接的指向。这次没有要求必须过期，也没有要求访问口令。归档不自动撤销 |
| Q10 | 未配置则拒绝上传 | `UPLOAD_MAX_BYTES` 或允许类型未设置时，上传和转存都拒绝。不写默认大小。具体数字这次没有给 |
| Q12 | 管理员开通本地口令 | 无公开注册，不接企业身份源，不做多因素认证 |

这些答复没有推翻 D1。模块文档是否作为 HTML 的源数据，仍然是待点头的技术决定。
